# 价值投资

Agent Skill：**价值投资** v1.00。股票长期分析：生意质量、真实现金流、管理层、安全边际、机会成本。

收到股票代码即出十二模块完整报告。只做股票，不写加密货币指标。

兼容 Claude Code、Cursor、Codex、Hermes 及其他读取 `SKILL.md` 的助手。

版本记录见 [Releases](https://github.com/taraway/value-investing-skill/releases) 和 [CHANGELOG.md](CHANGELOG.md)。当前 **v1.00**。

## 安装

```bash
hermes skills install taraway/value-investing-skill

git clone https://github.com/taraway/value-investing-skill.git
```
